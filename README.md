# صانع لوحات المتحف — النادي الفيصلي السعودي

أداة لتصميم لوحات المتحف التعريفية: صورة + نص عربي + ترجمة إلى الإنجليزية والفرنسية، ثم تصديرها بدقة عالية للطباعة.

**للاستخدام:** افتح `index.html` في Chrome أو Edge (أو رابط GitHub Pages).

## التصاميم
| التصميم | الوصف |
|---|---|
| طولي | الصورة + صندوق نص تحتها (15% من ارتفاع اللوحة) |
| عرضي | الصورة + عمود نص على يسارها (15% من عرض اللوحة) |
| لوحة لكل سنة | 70×90 سم: لوحة مستقلة لكل محطة — السنة هجري/ميلادي، العنوان، الصورة، النص بالعربي والإنجليزي، وشريط السنوات |
| لوحة لكل سنة 60×80 | نفس تصميم لوحة لكل سنة بمقاس 60×80 سم |

## الميزات
- ترجمة آلية من العربية إلى الإنجليزية والفرنسية (تحتاج إنترنت) مع إمكانية التعديل اليدوي.
- يعمل بدون إنترنت (الخطوط ومكتبة التصدير مدمجة).
- تصدير JPG / PNG بجودة ×2 / ×3 / ×4.
- **📚 اللوحات المحفوظة (المكتبة):** كل لوحة تُحفظ مستقلة بصورها ونصوصها، وتُفتح لاحقاً للتعديل. اللوحة المفتوحة من المكتبة تُحفظ تعديلاتها فيها تلقائياً. «لوحة جديدة» أو فتح لوحة أخرى لا يضيّع العمل الحالي: يُحفظ في المكتبة أولاً.
- **💾 حفظ الكل:** ملف JSON واحد فيه كل لوحات المكتبة بصورها ونصوصها. **📂 فتح ملف** يدمجه مع المكتبة، ولكل لوحة تُعتمد النسخة الأحدث، فيمكن إرسال الملف للمدير واستلامه بعد التعديل.
- الجوال للمعاينة والتعديل (تبويبان)، والتصدير النهائي من الكمبيوتر: «حفظ الكل» في الجوال ثم «فتح ملف» في الكمبيوتر.

## الملفات
```
index.html                 الصفحة الرئيسية
css/style.css              التنسيقات
js/app.js                  المنطق (الواجهة، الترجمة، التصدير)
js/library.js              مكتبة اللوحات المحفوظة وملف «حفظ الكل»
js/years.js                لوحات السنوات (70×90 و60×80)
js/fonts-en.js             خط Barlow Semi Condensed للإنجليزي في لوحات السنوات (SIL OFL)
js/logo.js                 شعار النادي
js/fonts.js                الخطوط المدمجة (Tajawal, Playfair Display — SIL OFL)
js/vendor/html-to-image.js مكتبة التصدير (MIT)
tests/run-tests.mjs        الاختبارات
```

## الاختبارات
قبل كل رفع: `node tests/run-tests.mjs` (يحتاج Chrome و Node 22 أو أحدث). يعرض ويصدّر كل اللوحات، ويتحقق من حفظ الإعدادات واستقلال لوحتي السنوات والمكتبة وفتح المشاريع القديمة.

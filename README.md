# صانع لوحات المتحف — النادي الفيصلي السعودي

أداة لتصميم لوحات المتحف التعريفية: صورة + نص عربي + ترجمة إلى الإنجليزية والإسبانية، ثم تصديرها بدقة عالية للطباعة.

**للاستخدام:** افتح `index.html` في Chrome أو Edge (أو رابط GitHub Pages).

## التصاميم
| التصميم | الوصف |
|---|---|
| طولي | عمود نص بجانب الصورة + صندوق نص سفلي |
| عرضي | صورة كبيرة + صندوق نص سفلي |
| جانبي | شعار ونصوص في عمود جانبي + الصورة |
| خط زمني | محطات تاريخية على خط متدرّج |
| جداري | تصميم جداري للمحطات (يشارك بيانات الخط الزمني) |

## الميزات
- ترجمة آلية من العربية إلى الإنجليزية والإسبانية (تحتاج إنترنت) مع إمكانية التعديل اليدوي.
- يعمل بدون إنترنت (الخطوط ومكتبة التصدير مدمجة).
- تصدير JPG / PNG بجودة ×2 / ×3 / ×4.
- حفظ المشروع وفتحه كملف JSON.

## الملفات
```
index.html                 الصفحة الرئيسية
css/style.css              التنسيقات
js/app.js                  المنطق (الواجهة، الترجمة، التصدير)
js/wall.js                 التصميم الجداري
js/logo.js                 شعار النادي
js/fonts.js                الخطوط المدمجة (Tajawal, Playfair Display — SIL OFL)
js/vendor/html-to-image.js مكتبة التصدير (MIT)
```

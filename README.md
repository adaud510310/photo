# صانع لوحات المتحف — النادي الفيصلي السعودي

أداة لتصميم لوحات المتحف التعريفية: صورة + نص عربي + ترجمة إلى الإنجليزية والفرنسية، ثم تصديرها بدقة عالية للطباعة.

**للاستخدام:** افتح `index.html` في Chrome أو Edge (أو رابط GitHub Pages).

## التصاميم
| التصميم | الوصف |
|---|---|
| طولي | عمود نص بجانب الصورة + صندوق نص سفلي |
| عرضي | صورة كبيرة + صندوق نص سفلي |
| جانبي | شعار ونصوص في عمود جانبي + الصورة |
| خط زمني | محطات تاريخية على خط متدرّج |
| جداري | تصميم جداري للمحطات (يشارك بيانات الخط الزمني) |
| OPTION 4 | لوحة جدارية مطابقة لتصميم OPTION 4 (8 محطات) بالعربية والإنجليزية |

## الميزات
- ترجمة آلية من العربية إلى الإنجليزية والفرنسية (تحتاج إنترنت) مع إمكانية التعديل اليدوي.
- يعمل بدون إنترنت (الخطوط ومكتبة التصدير مدمجة).
- تصدير JPG / PNG بجودة ×2 / ×3 / ×4.
- **📚 اللوحات المحفوظة (المكتبة):** كل لوحة تُحفظ مستقلة بصورها ونصوصها، وتُفتح لاحقاً للتعديل. اللوحة المفتوحة من المكتبة تُحفظ تعديلاتها فيها تلقائياً. «لوحة جديدة» أو فتح لوحة أخرى لا يضيّع العمل الحالي: يُحفظ في المكتبة أولاً.
- **💾 حفظ الكل:** ملف JSON واحد فيه كل لوحات المكتبة بصورها ونصوصها. **📂 فتح ملف** يدمجه مع المكتبة، ولكل لوحة تُعتمد النسخة الأحدث، فيمكن إرسال الملف للمدير واستلامه بعد التعديل.
- الجوال للمعاينة والتعديل (تبويبان)، والتصدير النهائي من الكمبيوتر: «حفظ الكل» في الجوال ثم «فتح ملف» في الكمبيوتر.
